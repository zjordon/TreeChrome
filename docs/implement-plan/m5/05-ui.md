# M5 段 E：@tw/console-ui + sidepanel/options

> 分支 `feat/m5-ui`。前置：段 A（骨架/协议）、段 D（SW 运行时可对接）。
> 纪律：**console-ui 禁 chrome.\***（biome overrides，段 A 已接线）——组件只收 props/回调，
> chrome 交互全在 apps/extension 粘合层（`entrypoints/*/main.tsx` + `src/ui-glue/`）。
> 这是架构 §1 原则 3（侧边栏与 web 控制台共享组件）的执行面：M6 web-console 零改动复用的前提。
> 验收：组件测试（vitest + @testing-library/react + jsdom）全绿覆盖率 ≥85% + 真机侧边栏/
> options 手工过单（与段 D smoke 串联）。

## 1. console-ui 组件清单（M5 面）

| 组件 | 职责 | 关键 props |
|---|---|---|
| `ThemedRoot` | CSS 变量主题容器（亮/暗 `prefers-color-scheme`，段 A 骨架扩） | children |
| `TaskBar` | 任务输入 + 附件选择/清单 + 起跑/停止控制 | `task`, `onTaskChange`, `attachments: AttachmentInfo[]`, `onPickFiles(files: File[])`, `onRemoveAttachment(id)`, `runStatus`, `onStart`, `onStop` |
| `RunTimeline` | 事件流渲染（seq 顺序）：step 分组（step_start…step_end 折叠体）内 tool_call（动作名+参数摘要）/tool_result（success/error 着色）/model_result（usage 徽章）/anomaly（警示色） | `events: JournalEvent[]`, `discardedBeforeSeq`, `stepCount` |
| `PermissionCard` | 权限确认卡：capability 标签（中文动作名）+ host + 动作参数表 + 元素定位（bbox/xpath 文本）+ 三按钮 | `req: PermissionCardPayload`, `onResolve(verdict)`, `expiresAt`（倒计时条） |
| `SubmitCard` | submit 预确认卡：字段摘要表（≤8，password 已打码）+ 确认/取消 | `req`, `fields: {name, value}[]`, `onConfirm`, `onCancel` |
| `StatusLine` | run 状态徽章（running/awaiting-*/done/error/interrupted）+ 步数 + 耗时 | `snapshot: RunJournalSnapshot 概要投影` |
| `FinalResult` | done 后 final_result 展示（is_successful 着色 + attachments 链接位） | `finalResult`, `isSuccessful`, `attachments` |
| `ProviderCardForm` | provider 卡表单（增/改/删/测试连接） | `card?: ProviderCardDto`, `onSave`, `onTest: () => Promise<{ok, message}>` |
| `ProviderList` | 卡列表 + active 选择 + fallback 链排序 | `cards`, `activeCard`, `onActivate`, `onEdit` |
| `GrantsView` | always 授权表（capability/host/时间）+ 撤销 | `grants: Grant[]`, `onRevoke(grant)` |
| `SkillListView` | 技能列表只读（host/slug/来源/蒸馏时间） | `cards: SkillCard[]` |
| 共享件 | `Button/Badge/Field/Table` 极简基础件（不引组件库——依赖纪律） | — |

事件渲染的文本裁剪/折叠（长参数/长结果）是 RunTimeline 内建行为（工具参数 500 字符折叠、
结果 1000 字符展开式）——细则实施时按 journal 压缩投影（段 D §4.1）对齐。

## 2. apps/extension 装配（粘合层）

```
entrypoints/sidepanel/main.tsx   # React 挂载 + Port 连接管理（断线重连指数退避）+
src/ui-glue/                     #  协议信封 ↔ 组件 props 适配器
  sidepanel-app.tsx              #  TaskBar/RunTimeline/权限卡浮层/StatusLine/FinalResult 组态
  port-client.ts                 #  Port 封装（connect/重连/请求-响应 token 配对）
entrypoints/options/main.tsx
  options-app.tsx                #  ProviderList/ProviderCardForm/GrantsView/SkillListView
                                  #  （读写走 message-router 单发消息，不直碰 chrome.storage——
                                  #   单一写者=SW，避免双端竞态）
```

- 权限卡浮层：`permission-request` 到达 → 置顶渲染 PermissionCard；多卡排队（守卫链逐动作串行，
  同时至多一张——core 语义保证；UI 防御性数组）；
- `awaiting-permission` 期间 sidepanel 关闭再打开：journal 快照恢复 + 竖卡重弹
  （policy-bridge 的 Port 广播面向连接即发——重连时 SW 补发挂起卡，实施细节在 port-server）。

## 3. 主题与视觉

- 单 CSS 文件 + CSS 变量（`--tc-bg/--tc-fg/--tc-accent/--tc-danger…`）；亮暗两套变量
  `@media (prefers-color-scheme)`；视觉打磨后置（M5 只求清晰可用）；
- 图标：内联 SVG 极少量（play/stop/paperclip）；不引图标库。

## 4. 测试

- 组件测试：每组件正常路径 + 关键分支（RunTimeline 的 10 类事件渲染、PermissionCard 三按钮
  回调与倒计时、SubmitCard 字段表截断、ProviderCardForm 校验（protocol 必填/baseUrl 形态））；
- glue 适配器：信封→props 映射纯函数单测（token 配对、ack 回发）；
- Port 重连逻辑：fake Port（事件注入）单测；
- **不测** chrome.* 本体（粘合层薄、真机 smoke 覆盖）。

## 5. 出界项（登记）

- web-console 宿主与 SSE 桥（M6）；技能编辑器/draft 审阅 UI（M7）；i18n；截图/视觉预览位
  （vision 模式截图在 journal 有 data 引用时展示——M5 只留扩展位，不实现）。
